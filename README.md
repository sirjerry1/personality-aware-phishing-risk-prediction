# Personality-Aware Phishing Risk Prediction Using Machine Learning

## Overview

This project is a final-year cybersecurity research project developed at Miva Open University.

The system investigates whether personality traits influence an individual's susceptibility to phishing attacks by combining psychological assessment with machine learning techniques.

Participants complete:

- Informed Consent
- Demographic Questionnaire
- Ten-Item Personality Inventory (TIPI)
- Five simulated phishing scenarios
- Confidence and feedback questionnaire

The collected data is later analysed using machine learning models to predict phishing susceptibility.

---

## Research Objectives

- Collect personality and behavioural data.
- Simulate realistic phishing decision-making.
- Build predictive machine learning models.
- Explain predictions using SHAP.
- Develop an interpretable phishing risk prediction system.
